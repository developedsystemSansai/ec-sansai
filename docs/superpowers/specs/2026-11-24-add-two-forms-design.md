# เพิ่มแบบฟอร์ม 2 ฉบับ (landing + app) — design สั้น

## เจตนา
ให้ผู้วิจัยและกรรมการโหลดฟอร์ม Word 2 ฉบับได้ ณ จุดที่ต้องใช้จริง โดยไม่ต้องพึ่งลิงก์ Google Drive ตัวใหม่

## ไฟล์
- `forms/EC-amendment-response.docx` — แบบแสดงส่วนแก้ไขเพิ่มเติมตามข้อเสนอแนะของคณะกรรมการ (ผู้วิจัยกรอก)
- `forms/EC-committee-review-report.docx` — แบบรายงานผลการพิจารณาจริยธรรมการวิจัยในมนุษย์ (กรรมการกรอก)
(ชื่อไฟล์ภาษาอังกฤษ เพราะไฟล์ต้นฉบับชื่อไทยหายตอนอัปโหลด และชื่อ ASCII ปลอดภัยกับ URL — เป็น call ของผม)

## จุดที่แก้
1. **landing `documents.html`** — แท็บ "เอกสารเพิ่มเติม": เพิ่มการ์ดฟอร์มแก้ไข (badge 9→10) ใช้คลาส `dm-item` เดิม ปุ่ม "ดาวน์โหลด (.docx)"
   ฟอร์มกรรมการ **ไม่ขึ้นบน landing**
2. **app โมดัล "ยื่นเอกสารแก้ไข"** (`modal-revision`) — ปุ่มดาวน์โหลดฟอร์มแก้ไข ชี้ไปไฟล์ใหม่ (แทนลิงก์ Drive เดิมที่ใช้งานเดียวกัน จะได้ไม่มีสองเวอร์ชัน)
3. **app หน้า "ดาวน์โหลดแบบฟอร์ม"** (`DOCUMENT_LINKS`) — ฟอร์มแก้ไขอยู่กลุ่ม "เอกสารประกอบอื่นๆ"; ฟอร์มกรรมการแสดงเฉพาะ เจ้าหน้าที่/แอดมิน
4. **app โมดัลประเมินของกรรมการ** (`modal-eval`) — ปุ่มดาวน์โหลดฟอร์มรายงานผล ข้างปุ่ม "ดาวน์โหลดแบบฟอร์มการอ่าน" เดิม (กรรมการไม่มีเมนูดาวน์โหลดแบบฟอร์ม จุดนี้คือที่ที่เขาทำงานจริง)

## Non-goals
ไม่แก้ backend (code.gs) / ไม่อัปโหลด Drive / ไม่แก้เนื้อหาใน .docx / ไม่ทำเป็นช่องบังคับแนบ

## วิธีตรวจ
เปิดทั้งสองหน้าด้วยเบราว์เซอร์จริง: ลิงก์โหลดได้ ไฟล์ตรงต้นฉบับ (checksum) ไม่มี console error และฟอร์มกรรมการไม่โผล่ในมุมมองผู้วิจัย
