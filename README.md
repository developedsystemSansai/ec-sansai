# EC Sansai — เว็บยื่นจริยธรรมวิจัย (ฉบับใหม่)

เว็บเก่า ไม่สมบูรณ์. ตอนนี้สมบูรณ์. หน้าตา modern. ฟังก์ชันเหมือนเดิม.

## ใช้ยังไง
1. เอาโฟลเดอร์ `ec-sansai-main/` ไปวางทับของเก่า.
2. Deploy เหมือนเดิม.
3. จบ. ไม่ต้องลงอะไรเพิ่ม.

`code.gs` กับ `config.js` ไม่แตะ. Backend เก่าใช้ได้.

## มีอะไรในกล่อง
- `ec-sansai-main/` — เว็บ 10 หน้า + รูป. อันนี้ของจริง.
- `docs/` — รายงาน. อ่านถ้าอยากรู้ละเอียด.
- `tests/` — สคริปต์เทส. รันซ้ำได้.

## แก้อะไรไป
- `app.html` ท้ายไฟล์ขาด. ต่อให้ครบ.
- อีโมจิค้าง. เปลี่ยนเป็นไอคอน.
- ไอคอนฝังในหน้า. ไม่พึ่ง CDN แล้ว. เน็ตโรงพยาบาลบล็อก ก็เห็นไอคอน.
- ไอคอน `ti-child` ไม่มีจริง. เปลี่ยนเป็น `ti-mood-kid`.
- หน้าตา modern. หัวเมนูกระจก. การ์ดมน. ปุ่มแคปซูล. ฟอนต์หัว Sarabun.
- หน้าแรก เพิ่มแผงทางลัด. ป๊อปอัปสวยขึ้น.
- กด Tab ได้ มีกรอบโฟกัส. สีอ่านชัดขึ้น.

JS เก่า ไม่เปลี่ยน (ยกเว้นข้อความอีโมจิ -> ไอคอน). เพิ่มสคริปต์เล็ก 1 อัน ใน `app.html` ช่วยคีย์บอร์ด.

## เทสแล้ว
- กดทดสอบ 20 จาก 20 ผ่าน.
- JS error 0.
- หน้าไม่ล้นจอ.
- ปัญหาการเข้าถึง 59 -> 36.

เหลือ 36: ปฏิทินหน้าแรก. JS เก่าวาดผิด role. ต้องแก้ใน JS. ยังไม่แตะ.

## ยังไม่เทส (สำคัญ)
เทสออฟไลน์เท่านั้น. ไม่มี GAS. ไม่เห็นข้อมูลจริง.
ก่อนขึ้นจริง ลอง:
- ล็อกอินจริง
- ยื่นโครงการ
- อัปโหลดไฟล์
- เปิดมือถือ

เจอพัง บอกชื่อหน้า.

## ถอยกลับ
ลบบล็อก `<style>` เหล่านี้ในไฟล์ได้ทีละอัน:
`modern`, `modern-app`, `lp-refresh`, `pg-refresh`, `ann-refresh`, `ux-refresh`.

อย่าลบ `icons-local`. ลบแล้วไอคอนหาย.

## เพิ่มไอคอนใหม่
ไอคอนไม่มีฟอนต์รวมแล้ว. เพิ่มชื่อใหม่ ต้องเพิ่มกฎ CSS `.ti-ชื่อ` เอง ใน `<style id="icons-local">`.
